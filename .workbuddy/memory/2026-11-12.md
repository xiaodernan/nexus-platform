## D965 — Eureka 优雅关闭裸调 async stop(): 反注册 DELETE 从未发出

- 编号: D963 / D964 被并发 lane 的真实单元占用, 本单元顺延 D965。
- 真实缺陷: apps/ai/nexus_ai/discovery.py 的 Registration.stop 是 async def, 其持有的 py_eureka_client
  客户端 stop() 同为 async def (内部先取消心跳 renew 定时器, 再 await DOWN register + cancel DELETE 两条网络写)。
  修复前关闭钩子裸调 self.client.stop(), 只创建协程从不调度 -> 反注册 DELETE 永不发出, 心跳定时器永不取消,
  退出抛 RuntimeWarning: coroutine was never awaited; 外围 try/except 抓不到 (裸调当刻不抛)。opt-in 注册面下
  已死 AI 副本在 Eureka 残留到 10s 租约自然过期, lb:// 边缘仍可能把流量派给它。与 D962 恰成反向: 那边同步
  阻塞调用压在 async 事件循环上, 这边 async 调用被完全留在循环外。
- 修复 (单行): await asyncio.wait_for(self.client.stop(), timeout=_DEREGISTER_TIMEOUT_S), 常量 2.0 秒。
  await 让反注册真正发出; bound 守住 registry 挂起时 shutdown 永不阻塞的契约 (超时后 10s 租约自然过期);
  asyncio.TimeoutError 是 Exception 子类, 既有 except Exception 仍 log-and-degrade。调用链, 心跳, opt-in
  环境门, fail-open boot 全部不动; 无客户端库改写, 无新依赖。
- 可证伪证明: 离线探针 apps/ai/tests/test_eureka_deregister_is_awaited.py 四臂 (正向置位 / falsifier 丢协程置
  False + RuntimeWarning / 挂起不阻塞 / 超时常量配置)。产品代码单行翻转回裸调, 正向臂 RED 并复现真实
  coroutine was never awaited 警告; 恢复后 GREEN。
