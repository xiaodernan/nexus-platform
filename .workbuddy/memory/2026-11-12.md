  客户端 stop() 同为 async def (内部先取消心跳 renew 定时器, 再 await DOWN register + cancel DELETE 两条网络写)。
  修复前关闭钩子裸调 self.client.stop(), 只创建协程从不调度 -> 反注册 DELETE 永不发出, 心跳定时器永不取消,

  await 让反注册真正发出; bound 守住 registry 挂起时 shutdown 永不阻塞的契约 (超时后 10s 租约自然过期);

  coroutine was never awaited 警告; 恢复后 GREEN。

## D972 — AI 工具缓存 expiry heap 随 LRU 驱逐无界增长, 推翻 D903 bounded by the cap 承诺: 可证伪修复

- 编号: D970 (platform mode 未设) / D971 (security job 浅克隆) 两个真实单元被并发 lane 连续占用,
  本单元再顺延 D972。
- 真实缺陷: apps/ai/nexus_ai/tools/registry.py 的 _Cache 用 _store OrderedDict 做 cap=max_entries 的
  LRU (D903 门 apps/ai/tests/test_d903_cache_is_bounded.py 只断言 len(_store) <= 8), D913 又加
  _expiry_heap 小顶堆做摊还 O(log n) 过期扫描。set() 每次写 push 一个 (expires, ck), 但 heapq 没有
  O(log n) 任意删除: LRU popitem 驱逐或覆盖写后, 被取代的 tuple 留在堆里, 只有 _sweep_expired
  弹出且 TTL 到期才走 (冻结时钟下永不发生)。实测 cap=8 / 2000 次不同参数写 -> store=8 但 heap=2000
  (250x); 单 key 覆盖 500 次 -> store=1 但 heap=500。每个 tuple 带 (spec.name, canonicalized-args-json),
  内存与扫描成本随见过的 DISTINCT ARGS 增长, 直接违背 D903 docstring 自己写的 bounded by the cap;
  已发门的门只查 _store 从不查 heap, 所以 CI 看不见这个泄漏。
- 修复: 给堆 tuple 加 generation。_seq 单调计数, _heap_token[ck] 记每个在库 key 唯一 live tuple 的 seq
  (纯 store 成员过滤无法区分同一 key 相同 expires 的重复写, 只有 generation 能); 每次 set 递增 _seq,
  覆盖该 key token, push (expires, seq, ck), 并删掉被 LRU 驱逐 key 的 token; 过期 get 也删 token,
  token 索引因此不泄漏。_sweep_expired 仅当 _heap_token.get(ck)==seq 且 store 仍持有相同 expires 才删
  store 项, 否则丢弃 stale tuple。堆长超过 _compact_factor*max_entries+1 时 _compact_heap() 从 live
  tuples 重建 + heapify, 每 O(cap) 次写摊还一次 O(len(heap)), 于是每写摊还仍 O(log n) (D913) 而堆
  变成 O(cap) (D903)。修复后实测 cap=8/2000 写 -> store=8 heap=10 token=8 bound=17;
  cap=4096/20000 写 -> heap=7706 <= 8193; 500 覆盖 -> heap=7。TTL/LRU/覆盖/过期扫描语义与
  D903/D913 台账逐字不动。
- 可证伪证明: 产品 compaction 门控单行翻成 if False: -> 正臂 RED 并报 the expiry heap grew to
  2000 on 2000 writes with cap=8, 恢复 GREEN。离线探针
  apps/ai/tests/test_d972_cache_heap_is_bounded.py 6 臂 (fake clock, 无 Redis/DB/网络/JVM): 正臂
  2000 次 churn 后堆有界且 len(_heap_token)==len(_store); falsifier 把 _compact_heap monkeypatch 成
  no-op 要求堆回到写数增长 (==2000 -> RED); 覆盖/generation guard (stale tuple 过期不得驱逐 fresh
  value)/过期读删 token/D903 语义臂。3 次稳定 6 passed, ruff+mypy clean。
- 结构门禁: scripts/check_cache_heap_bounded.mjs, 30 corruption arms + 1 GREEN control, D954
  no-op guard, D959 行锚定标题, 第三元组槽读 expect tag; 补 ATLAS-PROBE 翻转臂 (本轮 forward 4 个
  offender 中唯一缺对应臂的一个), 使每个 forward offender 都有自己的 reddening twin; sweep gate
  用完整唯一串 if (self._heap_token.get(ck) == seq and entry is not None 避免 _compact_heap
  comprehension 里的同形 needle 造成 vacuous GREEN; GREEN control 用源码真实注释并显式 guard skipped。
- 接线: CI line 171 self-test 链, ATLAS reader + probe, STATUS D972 台账标题, 本工作日志。ci.yml
  保持 535 行。全量 verify_all --report 绿。
