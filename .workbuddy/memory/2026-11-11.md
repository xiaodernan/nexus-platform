## 第三轮（D890，同一天续做）
- 触发：D889 全量 `verify_all.mjs` 9m23s，其中 `check_line_cite_drift.mjs` **502137ms**（PASS*，靠超时重试）；D888 只修了另一个 reader。
- 根因：该 reader 的 `blobCache` key 是 `${blame commit}|${cited path}`，blame commit 随引用所在行变化 → 上千个不同 key → 上千次 `git show` spawn。
- 修法：主循环前一次性解析 ledger 平面（HEAD text + `blameByLine`）并复用；预扫描收集所有 `(ref,path)` key（原始拼写 + 唯一 suffix 解析），一次 `git cat-file --batch`（输入支持 `rev:path`）预填充缓存；未覆盖的 key 仍 fallback 到 `git show`（慢但不会错）。新增 `--no-prefetch` 开关做等价性对比。`verify_all.mjs` 从 SLOW 集合移除它。
- 实测：全量 **9604ms**（约 52x），`544/568` 及各 verdict 计数与优化前完全一致；DECISIONS.md 子集两引擎 stdout **逐字节相同（2728 bytes）**，4s vs 14s。提交 `b64542d`。
