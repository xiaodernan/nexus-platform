## 本轮踩过的坑（Windows/Git Bash，复用价值高）
- **`EUREKA_URL` 末尾带 `/` 再拼 `/apps` → `/eureka//apps` → Eureka Jersey 返回 404**。拆成 `EUREKA_BASE`（无尾斜杠，用于 REST 路径）和 `EUREKA_URL`（带尾斜杠，用于 fixture/defaultZone）。
- **MSYS 路径转换**：任何以 `/` 开头的 env 值传给原生 python 会被改写成 `D:/.../PortableGit/api/v1/health`。env 改传 `api/v1/health`（无前导斜杠），Python 内部再补 `/`。
- **Python `json.dumps` 默认在冒号后加空格**（`"app": "NAME"`），shell 里 `grep -q '"app":"NAME"'` 永远不匹配 → 用 `grep -qF "$app"`。
- **`curl -o` 写 `C:\...` 风格的 TMPDIR 不可靠**，且 `/eureka/apps` 是懒初始化 Jersey 端点不适合做 readiness；统一用 `/actuator/health` + 管道 grep。
- 另一工作区 `D:/内容创作平台` 并行跑 Maven/vitest 时会耗尽 Windows fork 资源（`Resource temporarily unavailable`）。给 smoke 加 `NEXUS_FEIGN_SKIP_BUILD=1`（jar 缺失则拒绝跳过），CI 仍始终构建。
